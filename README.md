# USB Audit - аудит и журналирование подключений USB-накопителей (Ubuntu 24.04, C17, GTK3)

Курсовой проект. Десктопное приложение: при вставке флешки в окне сразу появляется строка в таблице
и панель «Поле | Значение» со всей информацией об устройстве. Устройства идентифицируются по серийному номеру.

## Сборка и запуск
```bash
sudo apt install build-essential pkg-config libudev-dev libgtk-3-dev
make
./usbaudit              # графическое окно
./usbaudit --cli        # консольный режим
./usbaudit --history    # реестр в консоли
```
Root не нужен.

## Вкладки окна
- «Подключённые устройства» - таблица текущих флешек + панель «Сведения об устройстве» (время, узел, производитель, модель, серийный номер, VID:PID, объём, ФС, метка, UUID, точка монтирования, статус);
- «Реестр устройств» - все ранее виденные устройства (число подключений, первое/последнее подключение);
- «Журнал» - содержимое log-файла.

## Хранение данных (каталог data/)
- `usb_audit.log` - журнал событий START / CONNECT / DISCONNECT / STOP;
- `usb_registry.db` - файл-реестр известных устройств (TSV, ключ - серийный номер).

## Структура (ООП на C: struct + функции-методы с первым параметром `self`)
| Модуль | Класс | Назначение |
|---|---|---|
| usb_device | UsbDevice | данные устройства |
| usb_scanner | UsbScanner | чтение сведений через libudev, /proc/mounts |
| registry | Registry | файл известных устройств |
| logger | Logger | log-файл |
| gui | Gui | графическое окно GTK3, события udev |
| app, table | App, Table | консольный режим (--cli) |
