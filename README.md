# USB Audit - аудит и журналирование подключений USB-накопителей (Ubuntu 24.04, C17)

Курсовой проект. Программа отслеживает подключение флешек и сразу выводит таблицу
«Поле | Значение» со всеми сведениями об устройстве. Устройства идентифицируются по серийному номеру.

## Сборка и запуск
```bash
sudo apt install build-essential libudev-dev
make
./usbaudit              # мониторинг (вставляйте флешку)
./usbaudit --history    # реестр известных устройств
```
Root не нужен.

## Что показывается
Время подключения, узел (/dev/sdX), производитель, модель, серийный номер, VID:PID, объём,
файловая система, метка, UUID, точка монтирования, статус (НОВОЕ / ИЗВЕСТНОЕ + число прошлых подключений).

## Хранение данных (каталог data/)
- `usb_audit.log` - журнал событий START / CONNECT / DISCONNECT / STOP;
- `usb_registry.db` - файл-реестр известных устройств (TSV, ключ - серийный номер).

## Структура (ООП на C: struct + функции-методы с первым параметром `self`)
| Модуль | Класс | Назначение |
|---|---|---|
| usb_device | UsbDevice | данные устройства |
| usb_scanner | UsbScanner | чтение сведений через libudev, /proc/mounts |
| registry | Registry | файл известных устройств |
| logger | Logger | log-файл |
| table | Table | вывод таблицы |
| app | App | главный цикл, связывает всё |
